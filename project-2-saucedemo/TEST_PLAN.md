# 🧪 SauceDemo — QA Test Plan

## 1. Project Overview

**Project:** SauceDemo QA Case Study  
**Project Type:** Web Application Testing  
**Testing Approach:** Manual QA + Automated Testing  
**Automation Framework:** Playwright  
**Language:** JavaScript  

This project demonstrates practical QA testing of a public demo e-commerce web application.

---

## 2. Test Objective

The objective is to verify the main user flows of the application and identify functional, usability, and validation issues.

The project demonstrates practical Junior QA skills including:

- test planning;
- test case design;
- exploratory testing;
- functional testing;
- negative testing;
- bug reporting;
- screenshot evidence;
- Playwright automation;
- QA documentation.

---

## 3. Scope of Testing

The following areas will be tested:

### Authentication

- valid login;
- invalid login;
- empty username;
- empty password;
- locked user behaviour.

### Product Catalogue

- product list loading;
- product information;
- sorting;
- product navigation.

### Shopping Cart

- add product;
- remove product;
- multiple products;
- cart counter;
- cart contents.

### Checkout

- customer information validation;
- checkout overview;
- order completion;
- missing required fields.

### Navigation

- menu;
- back navigation;
- logout;
- reset application state.

---

## 4. Testing Types

The project will include:

- Functional Testing
- Negative Testing
- UI Testing
- Validation Testing
- Exploratory Testing
- Regression Testing
- Automated Testing
