# Project 4 — SQL & Database Testing

## Overview
Practical entry-level database testing project using SQLBolt training databases. The project demonstrates SQL as a QA tool for retrieving and validating data, filtering records, checking aggregates, validating relationships between tables, and detecting missing values.

## Skills
SELECT • WHERE • AND/OR • BETWEEN • ORDER BY • COUNT • GROUP BY • JOIN • IS NULL / IS NOT NULL • expected vs actual validation • QA documentation
