# SQL Database Testing — Test Plan

## Objective
Validate sample database records with SQL and demonstrate practical database-testing skills relevant to a Junior QA role.

## In Scope
Data retrieval; column selection; text/numeric filtering; AND/OR; ranges; sorting; counting; grouping; JOIN validation; NULL validation.

## Out of Scope
Performance, security/permissions, stored procedures, transactions, production databases, and data modification.

## Environment
SQLBolt; Movies, Boxoffice, Employees and Buildings sample tables.

## Approach
1. Define the validation goal.
2. Execute a read-only SQL query.
3. Compare actual and expected results.
4. Mark PASS only when the output was visibly confirmed.
5. Preserve selected screenshots as evidence.

## Exit Criteria
Core read-only SQL scenarios completed, including JOIN and NULL checks, with results documented.
