# QA Factory v1.3 — короткий посібник українською

Це локальна програма для Windows, а не готовий публічний вебсервіс. Вона перевіряє ZIP-проєкти, зберігає звіти, запускає регресійні тести для трьох відомих ігор після явного підтвердження та надає локальний кабінет замовника.

## Запуск

1. Розпакуйте основний ZIP і встановіть Python 3.10+.
2. Для автоматичної статичної перевірки покладіть свої архіви до `QA_INBOX` і запустіть `START_RELEASE_GATE_WINDOWS.bat`.
3. Результати відкрийте через `QA_RESULTS/OPEN_RELEASE_MATRIX.html`.
4. Для перевірки власних ігрових ZIP у браузері встановіть Playwright Chromium і запустіть `TEST_GAMES_WINDOWS.bat`.
5. Для локальної форми заявки запустіть `START_CLIENT_PORTAL_WINDOWS.bat` і відкрийте `http://127.0.0.1:8790`.

## Рівні рішення

- `BLOCKED` — підтверджена серйозна помилка або невдалий функціональний тест. Випуск блоковано.
- `HOLD_FOR_REVIEW` — бракує перевірок, є непідтверджені попередження або потрібне погодження фахівця.
- `READY_FOR_STAGING` — можна випробовувати на тестовому середовищі після підтвердження; це **не** гарантія готовності до публічного запуску.

За результатами перевірки 14 справжніх ZIP-пакетів один початковий шаховий реліз було заблоковано, тринадцять потребують подальшої перевірки. Не перевірено справжній апаратний 3D та якість музики на слух.

## Безпека

Не розміщуйте локальний кабінет одразу на Netlify чи іншому публічному сервері. Не публікуйте клієнтські ZIP, персональні дані або вихідні коди без дозволу. До GitHub наразі є доступ на читання, але запис блокується помилкою 403.
