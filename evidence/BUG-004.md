# BUG-004 — Login button is skipped during keyboard navigation

- ID: BUG-004
- Title: Login button is skipped during keyboard navigation
- Reporter: Alexei
- Date: 2026-09-07
- Environment: SauceDemo
- Browser: Google Chrome
- OS: Windows 10
- Page / URL: Login page
- Severity: Minor
- Priority: P2
- Repro Rate: Always
- Related Test Case: TC-015 — Keyboard navigation

## Summary

The Login button cannot be reached in the expected keyboard navigation sequence using the Tab key.

## Steps to Reproduce

1. Open the SauceDemo login page.
2. Use the **Tab** key to navigate through the interactive controls.
3. Move the keyboard focus through the **Username** field.
4. Continue to the **Password** field.
5. Press **Tab** again.
6. Observe the keyboard focus behaviour.

## Expected Result

Keyboard focus should move through the login form in a logical order:

**Username → Password → Login**

The Login button should receive visible keyboard focus and be operable from the keyboard.

## Actual Result

Keyboard focus moves through the Username and Password fields, but the Login button is skipped when continuing with the Tab key.

The focus moves to other elements instead of the Login button.

## Impact

Users who rely on keyboard navigation may be unable to reach and activate the Login button using the expected Tab navigation sequence.

## Evidence

Manual test performed during:

**TC-015 — Keyboard navigation**

Result:

**❌ Failed**
